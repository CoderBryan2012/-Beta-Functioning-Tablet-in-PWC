# (Beta) Functioning Tablet in PWC (Plant with Coding on Roblox)
### Explanation:
This project uses mainly LAU UI to create a functioning tablet. 
- **🥇 Achievement:** Won 1st place in the **Lau Random Ahh Competition** on Lated Graham's discord server.
## Features
- **Up-To-Date:** Uses LAU version 5.5.0.
- **Broad & General:** Useful for farming, market, drone control and selling.

## Quick Start
1. **Unpack the Files**

Download and copy text from all of the files (.laum for module scripts & .lau for normal scripts).

2. **Preprare to run the Files**

Put the [normal script](main.lau) in the file in the drone.

3. **Experiment / Feedback**

After running the script, you can experiment with the code or report issues / ideas in the [issues section](https://github.com/CoderBryan2012/-Beta-Functioning-Tablet-in-PWC/issues).
### Prerequisites
- Game Module
- Drone Module
- String Module
- Player Module
- Market Module
- Display Module
- Garden Module
- DroneV2 Module
